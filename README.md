`Python` · `FastAPI` · `React` · `TypeScript` · `Google Gemini`

### GenomeIQ — *Final Year Project*
Engineered an end-to-end machine learning system that classifies raw genomic data to streamline gene identification. Full-stack delivery with a Python backend and SVM classifier, a React frontend, and MongoDB for application data. Presented the technical feasibility and social impact to KPK government officials, resulting in formal appreciation and consideration for regional implementation by KPITB.

`Python` · `SVM` · `React` · `MongoDB` · `Machine Learning`

### AI LinkedIn Content Automation
Built a Make.com workflow that researches topics in a chosen niche and generates five AI topic suggestions for human approval. The selected topic is passed to an LLM that writes a structured LinkedIn post with contextual hashtags, then publishes automatically via the LinkedIn API — a reusable, human-in-the-loop content pipeline.

`Make.com` · `AI / LLM` · `LinkedIn API` · `Workflow Automation`

### Earlier DevOps Background — *Kubernetes, CI/CD & Observability*
Migrated a legacy stack onto a GitOps-driven Kubernetes platform with Terraform and Argo CD, designed multi-stage Jenkins pipelines with automated rollbacks, and rolled out a Prometheus, Grafana, Loki and ELK observability stack with alerting runbooks.
